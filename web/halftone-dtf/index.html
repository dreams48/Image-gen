Avant de presser

  1. Importez le PNG tel quel dans votre RIP, à 100 % : la résolution est inscrite dans le fichier.
  2. Désactivez le lissage ou le « choke » du blanc s'il ronge les petits points ; gardez le blanc à 100 % sous chaque point.
  3. Le fichier ne contient que des pixels pleins ou transparents : aucun voile de blanc ne s'imprimera entre les points.
  4. Faites un test sur une chute de tissu : la taille de point minimale dépend de votre film et de votre poudre.
